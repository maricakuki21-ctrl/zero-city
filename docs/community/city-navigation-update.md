# 零号城界面与玩家公告机制

全城动态是「进城」下的独立入口。打开全城动态不再自动展开「零号城」分类；进入闲聊广场、投票大厅、收藏卡册等实际子页面才自动展开相应分类。分类本身仍可手动展开收起。

全城动态中的玩家公告优先显示两条，两行摘要；可展开全部公告，点标题进入原始议题。投票大厅新增类型、状态筛选及可展开的发布规则。

## 玩家如何发布公告

- L0 可以阅读、参与讨论。L1 居民可以提交正式议题与投票。居民资格仍由管理员根据贡献确认。
- 在「零号城 → 城市活动 → 投票大厅 → 提交议题」选择「玩家公告」。
- 默认投票 24 小时、至少 3 人参与、支持率达到 60%，通过后在全城动态展示 7 天。具体规则以每个议题显示的快照为准。
- 一人一票；充值和消费不增加票权。提交后正文与选项锁定。作者可以撤回，管理员可以下架，过期后讨论记录保留。
- 玩家公告与官方公告分开；投票不授予管理权限，也不直接执行付款、规则变更或正式服部署。

上述流程已先开放到独立社区测试站。正式站公告应说明测试范围，不宣称正式站已经部署该代码。
