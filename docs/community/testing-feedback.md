# 怎样反馈一个可复现的问题

测试入口见仓库根目录 TESTING.md。临时地址可能变化，请从该文件进入。

## 提交 Issue 时写清楚

1. 页面路径、浏览器和屏幕宽度。
2. 从登录开始的最少复现步骤。
3. 预期发生什么，实际发生什么。
4. 不含私人信息的截图或错误提示。
5. 测试的提交版本；不知道时说明测试时间和入口。

测试站没有真实供应商或支付配置时，模型请求失败不等于代码回归，请先检查环境说明。不要为测试进行真实充值。

## 验证 PR

对照 PR 的验证步骤测试，同时检查手机布局、空数据状态、错误提示和返回操作。
共享测试站只代表当前部署的版本，不能把它的表现当成任意未部署 PR 的测试结果。
代码贡献者可下载 CI 前端构建产物，或按照 README 在自己的环境启动对应提交。

测试反馈可以直接留在对应 PR 下。文档范围内的合并由自动化处理；业务功能需要维护者确认范围及检查结果。
