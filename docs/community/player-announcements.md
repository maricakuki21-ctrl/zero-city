# 城市活动：玩家公告与参与资格

## 唯一入口和边界

沿用「零号城 → 城市活动 → 投票大厅」。玩家公告是议题类型，不是另一套公告中心，也不授予玩家管理员权限。官方公告的管理员权限保持不变。

- L0：浏览、讨论议题；不能提交正式议题或投票。
- L1 / 管理员：提交议题，一人一票，不按充值、消费或积分增加票权。
- L1 资格仍由现有管理员确认贡献并记录依据；不承诺自动升级，不引入 L2。
- 类型：普通议题、玩家公告、城市活动、网站建议、规则提案。仅玩家公告达标后自动展示；其他类型只形成投票结果，不自动执行规则、付款或代码发布。

## 公告生命周期

提交即进入公开投票，正文、选项、规则和截止时间锁定；讨论使用原帖评论，不复制帖子。
公告选项固定为支持发布 / 暂不发布。投票到期，达到最少参与人数且支持率达标，自动出现在全城动态的「玩家公告」区域；未达标保留公开结果但不展示。

默认 24 小时投票、至少 3 人、支持率至少 60%、展示 7 天。可用服务环境变量调整新提案规则：
`CITY_ANNOUNCEMENT_VOTING_HOURS`、`CITY_ANNOUNCEMENT_MIN_VOTES`、`CITY_ANNOUNCEMENT_SUPPORT_PERCENT`、`CITY_ANNOUNCEMENT_DISPLAY_DAYS`。规则快照随提案保存，环境修改不改变旧提案。

作者或管理员可撤回公告，包括投票中和已经发布的公告；提前结束不等于通过。管理员可沿用原帖隐藏功能下架。过期不再突出展示，投票与讨论记录保留。

发布状态由锁定截止时间和真实票数推导，没有重复公告写入，不依赖另一个发布队列。到期后下一次读取即得到最新结果。

## 验收

验证 L0 讨论但不能投票、L1 创建和投票、重复同票幂等、改票拒绝、到期拒绝投票、通过/未通过/过期/撤回、隐藏后停止展示。检查全城动态与投票大厅桌面和移动端。仅先部署隔离测试站，不变更生产用户、余额或权限。
