# 社区共建基线

本次源代码整理以 2026-09-26 正式部署的 `city-arrival-20260926` 为基线。

- 后端取自正式构建源，不包含运行数据库、环境文件或私钥。
- 前端取自对应部署的工作目录，609 个公开素材与正式静态目录逐一校验 SHA-256。
- Harness 取自正式运行容器的源码和依赖清单。
- 保留原有 SQL 迁移，不篡改已执行迁移的校验和。
- 新增社区说明、Issue 模板、PR 模板、构建流程、演示 Compose 和 Dockerfile。
- 脱敏单测中的随机十六进制样本改为明确的虚构测试序列，行为不变。

独立测试站使用新的 PostgreSQL 和 Redis，不连接正式数据库。没有供应商账号和支付配置的功能不能在测试站完成真实交易。

## 当前限制

代码入库不代表历史功能已全部验收。首次 CI 结果及后续问题应在 Issues 中公开跟踪。
站内投票与 GitHub Issue 双向同步、每 PR 独立部署、自动生产发布尚未接通。
目前只对指定目录内的文档变更自动合并；其他变更由维护者验收，用户不必亲自操作 GitHub。
